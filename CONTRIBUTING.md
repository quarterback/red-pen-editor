# Contributing

Red Pen Editor is a free, open-source editorial skill, CLI, and MCP server.

## Development

Requires Node.js 20 or later. No package installation is needed to run tests.

```sh
npm test
npm run demo
```

Changes to editing rules should be tested against examples that distinguish redundant writing from necessary detail. Preserve attribution, qualifiers, numbers, conditions, and the writer's voice. Prefer tests of substantive editorial decisions over tests of word-count reduction alone.

Do not add third-party model or paid-service requirements to the default skill or MCP workflow. Optional providers must be clearly labeled.
